# Sift

**A Windows screen-region OCR app for printed text, code, and equations.**

Select an area of your screen, and Sift copies the recognized text to your clipboard.

## Features

- **Screen capture:** Drag to select a region.
- **Text recognition:** Supports English and Spanish, including accents.
- **Code mode:** Recognizes code punctuation and brackets.
- **Math mode:** Recognizes printed equations and can copy them as text or LaTeX.
- **Works locally:** Captures are processed on your computer.

## Limitations

Cursive or handwritten math symbols can still be misrecognized. Review the result before using it.
